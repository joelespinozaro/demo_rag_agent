# Ruta de aprendizaje: Data Science & IA

## Niveles

1. **Básico**: fundamentos de estadística y probabilidad, Python para análisis de datos (pandas, numpy), visualización de datos.
2. **Intermedio**: machine learning supervisado y no supervisado, feature engineering, evaluación de modelos.
3. **Avanzado**: deep learning (redes neuronales), procesamiento de lenguaje natural, sistemas de IA generativa (LLMs, RAG).

## Prerrequisitos

- Se recomienda base de matemáticas (álgebra lineal, cálculo básico) antes de iniciar el nivel Intermedio.
- El nivel Avanzado requiere haber aprobado machine learning supervisado del nivel Intermedio.

## Especializaciones sugeridas al finalizar

- Machine Learning Engineer
- Data Analyst
- Ingeniero de IA Generativa

## Recomendación de progresión

Reforzar estadística y Python antes de avanzar a modelos complejos; los proyectos prácticos con datasets reales son clave en cada nivel.
