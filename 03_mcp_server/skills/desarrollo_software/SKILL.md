# Ruta de aprendizaje: Desarrollo de Software

## Niveles

1. **Básico**: lógica de programación, fundamentos de un lenguaje (Python o JavaScript), control de versiones con Git.
2. **Intermedio**: estructuras de datos, POO, bases de datos relacionales (SQL), APIs REST con un framework (Django/FastAPI o Express/NestJS).
3. **Avanzado**: arquitectura de software, testing automatizado, contenedores (Docker), CI/CD, sistemas distribuidos.

## Prerrequisitos

- Para cursar Intermedio se requiere aprobar el módulo Básico o acreditar experiencia equivalente.
- Para cursar Avanzado se requiere haber completado al menos un proyecto final del nivel Intermedio.

## Especializaciones sugeridas al finalizar

- Backend (APIs, microservicios)
- Frontend (React/Vue)
- Full-stack

## Recomendación de progresión

Se recomienda no saltar niveles: cada nivel construye las bases necesarias para el siguiente, especialmente en fundamentos de programación y bases de datos.
