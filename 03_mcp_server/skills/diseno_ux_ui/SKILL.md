# Ruta de aprendizaje: Diseño UX/UI

## Niveles

1. **Básico**: fundamentos de diseño (color, tipografía, composición), principios de usabilidad.
2. **Intermedio**: investigación de usuarios (research), arquitectura de información, wireframing y prototipado (Figma).
3. **Avanzado**: design systems, testing de usabilidad, diseño de interacción avanzado, handoff con equipos de desarrollo.

## Prerrequisitos

- El nivel Intermedio requiere manejo básico de herramientas de diseño (Figma o similar).
- El nivel Avanzado requiere haber presentado al menos un prototipo evaluado en el nivel Intermedio.

## Especializaciones sugeridas al finalizar

- UX Researcher
- UI/Product Designer

## Recomendación de progresión

Priorizar práctica con research real y prototipado antes de profundizar en design systems, para no diseñar sin validar con usuarios.
